## Security Assessment

### The Good
- Global `IsAuthenticated` — all endpoints require authentication
- Action-level `HasPermission` enforcement on all CRUD endpoints
- `PermissionCode` enum prevents stringly-typed permission codes
- Service-layer validation rejects invalid/enum-mismatched codes
- `HasRoleLevel` ready for hierarchical role checks
- Safe-fail: without seed data, `HasPermission` denies all (returns 403)
- JWT authentication wired — `POST /api/v1/auth/login/` and `POST /api/v1/auth/refresh/`
- Audit history tracked on Role, Permission, RolePermission via `django-simple-history`

### The Bad
- No seed data — fresh database has zero roles/permissions, all `HasPermission` checks deny
