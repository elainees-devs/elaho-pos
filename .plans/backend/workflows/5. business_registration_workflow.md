## Data Model

### Business (`apps/businesses/models.py`)

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `name` | CharField(100) | required, MinLengthValidator(2) | Business display name |

**Table:** `businesses`
**Audit:** `HistoricalRecords` on all changes

## API Endpoints

### List / Search Businesses

**GET** `/api/v1/businesses/`

Auth: Required (superadmin)

**Query params:**
- `q` — search by name (case-insensitive `icontains`)

**Response (200):**
```json
[
  {
    "id": 1,
    "name": "Mama Njeri Shop",
    "slug": "mama-njeri-shop",
    "owner": null,
    "phone": "0711111111",
    "email": "shop@example.com",
    "address": "Nairobi, Kenya",
    "kra_pin": "A123456789B",
    "is_active": true,
    "is_deleted": false,
    "created_at": "2026-07-15T10:00:00Z",
    "updated_at": "2026-07-15T10:00:00Z"
  }
]
```

### Create Business

**POST** `/api/v1/businesses/`

Auth: Required + `IsSuperAdmin`

**Request:**
```json
{
  "name": "Mama Njeri Shop",
  "phone": "0711111111",
  "email": "shop@example.com",
  "address": "Nairobi, Kenya",
  "kra_pin": "A123456789B"
}
```

**Response (201):**
```json
{
  "id": 1,
  "name": "Mama Njeri Shop",
  "slug": "mama-njeri-shop",
  "owner": null,
  "phone": "0711111111",
  "email": "shop@example.com",
  "address": "Nairobi, Kenya",
  "kra_pin": "A123456789B",
  "is_active": true,
  "is_deleted": false,
  "created_at": "2026-07-15T10:00:00Z",
  "updated_at": "2026-07-15T10:00:00Z"
}
```

**Processing:**
1. Validate name is unique (slug collision handled in model)
2. Auto-generate slug from name
3. Create Business record (owner set to NULL)
4. Return business with slug

**Error responses:**

| Status | Condition |
|--------|-----------|
| 400 | Missing name, validation failure |
| 403 | Not a superadmin |
| 405 | GET instead of POST |

## Slug Generation

Slugs are auto-generated from the business name:

```python
def _generate_slug(self) -> str:
    base = slugify(self.name)
    slug = base
    while Business.objects.filter(slug=slug).exists():
        slug = f"{base}-{secrets.token_hex(3)}"
    return slug
```

| Name | Slug |
|------|------|
| Mama Njeri Shop | `mama-njeri-shop` |
| Mama Njeri Shop | `mama-njeri-shop-a1b2c3` |
| My Store | `my-store` |
| Café & Co. | `cafe-co` |

Slugs are immutable after creation.

## Security Assessment

### The Good

| Measure | Implementation |
|---------|---------------|
| Superadmin-only creation | `IsSuperAdmin` permission class |
| Soft-delete | `is_deleted` flag, queryset filters out deleted |
| Slug uniqueness | DB constraint + collision handling |
| Audit trail | `HistoricalRecords` on Business model |
| Owner PROTECT | Can't delete a user who owns a business |
| User business PROTECT | Can't delete a business with users assigned |

### Remaining Concerns

| # | Severity | Finding | Mitigation |
|---|----------|---------|------------|
| 1 | MED | **No slug-based routing yet** | Planned — `api/v1/b/{slug}/...` |
| 2 | MED | **No owner linking on creation** | Owner set to NULL; link after user creation |
| 3 | LOW | **No business search throttle** | Add throttle to prevent enumeration |
| 4 | LOW | **No `is_deleted` soft-delete handling** | ViewSet filters `is_deleted=False` but no restore endpoint |
